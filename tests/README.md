# Resume Output Tests

This directory contains tests to verify that different output variants are generated correctly.

## Running Tests

### Quick Test
```bash
make test
```

### Direct Execution
```bash
python tests/run_tests.py
```

### With pytest (if installed)
```bash
pytest tests/test_output_variants.py -v
```

## What Gets Tested

The tests verify that:

1. **Output files exist** - All expected variants are generated
2. **Canonical output** - Has both skills and statements blocks
3. **Skills-only variant** - Has skills but no statements
4. **Statements-only variant** - Has statements but no skills
5. **All outputs are different** - Each variant is distinct
6. **Top-N filtering with -1** - Setting N=-1 shows all statements (special "show all" value)
7. **Top-N filtering with specific value** - Setting N=3 shows only top 3 projects' statements
8. **Top-5 project details** - Has both skills and exactly 5 statement blocks (generated by default)

## Test Files

- `run_tests.py` - Standalone test runner (no dependencies)
- `test_output_variants.py` - Pytest-compatible tests (requires pytest)
- `__init__.py` - Package marker

## Top-N Project Filtering

The `top-n-projects-to-include-statements-blocks` setting controls which project statements are shown:

- **-1** (default): Show all project statements
- **0**: Show all project statements (legacy)
- **N > 0**: Show only the top N projects' statements based on importance order

The importance order is defined in `data/meta.yml` under `projects-importance-order-to-include-statements-blocks`.
